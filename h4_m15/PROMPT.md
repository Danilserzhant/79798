# Промпт: поиск рабочего сетапа H4 → M15 на BTCUSDT

Ты — квант-исследователь. Найди механический сетап «контекст на H4, вход на M15», который
даёт положительное матожидание **после комиссий** и **вне выборки, на которой его подбирали**.
Если такого нет — так и скажи, не подкручивай параметры до красивой кривой.

## Данные
- BTCUSDT spot Binance, 5m свечи, UTC, 2020-01 … 2026-08 (`weekly_levels/fetch_data.py`).
- H4 и M15 собираются ресемплом из 5m (H4: 00/04/08/12/16/20 UTC).
- Исполнение и выходы проверяются по 5m внутри M15, чтобы честно решить, что было раньше — стоп или тейк.

## Правила честного теста
1. **Никакого заглядывания вперёд.** H4-свеча используется только после её закрытия.
   Фрактал (свинг) считается подтверждённым только после закрытия N свечей справа.
2. **Вход:** по открытию следующей M15 после сигнальной, либо лимиткой — только если цена
   реально вернулась к цене лимитки после сигнала. Лимитка живёт ограниченное время.
3. **Если стоп и тейк в одной 5m-свече — считаем стоп.**
4. **Издержки:** 0,10% от цены на сделку туда-обратно (комиссия + проскальзывание), переводим в R:
   `cost_R = 0.001 * entry / |entry − SL|`. Мелкие стопы этим честно штрафуются.
5. **Одна позиция одновременно** на вариант; сигналы во время открытой сделки пропускаются.
   Максимальное удержание — 5 суток, потом выход по рынку.
6. **Разделение выборки:** подбор параметров только на 2020-01 … 2023-12 (train).
   2024-01 … 2026-08 (test) открывается один раз для отобранных кандидатов.
7. **Множественное тестирование:** честно указать, сколько вариантов перебрано. Сравнить с
   базой — случайные входы того же направления с тем же стопом/тейком.
8. **Критерии «работает»:** на train ≥150 сделок и expectancy > +0,10R после издержек;
   на test expectancy > 0, profit factor > 1,1, ≥ 4 из 7 лет в плюсе, просадка в R разумная.
   Без этих условий — не «работает».

## Семейства сетапов (симметрично лонг/шорт)
- **A. H4 sweep → M15 CHoCH.** H4-свеча прокалывает подтверждённый H4-свинг и закрывается обратно
  (снятие ликвидности). В течение K следующих H4 ждём на M15 слом структуры (закрытие за последним
  M15-свингом). Стоп за экстремум свипа. Вход: рынок / лимит в M15 FVG / 50% импульса.
- **B. H4 тренд → M15 откат + слом.** H4 тренд (EMA50 vs EMA200 и цена за EMA50). На M15 — снятие
  локального свинга против тренда и слом структуры по тренду. Стоп за M15-свинг.
- **C. H4 FVG → M15 подтверждение.** Свежий H4 FVG; цена возвращается в него; на M15 слом структуры
  внутри зоны. Стоп за FVG.
Параметры: размер фрактала, K (окно ожидания), тип входа, цель (1,5R / 2R / 3R / противоположная
H4-ликвидность), фильтр по H4-тренду, фильтр по сессии.
